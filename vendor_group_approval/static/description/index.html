Vendor Group Approval for Odoo 17

Build a clean, company-wise vendor approval workflow with configurable approval groups, sequence-based approval levels, approval history, email notifications, and clear visibility for approvers.

Separate Vendor Approval Models Multi-Company Ready Level-Based Workflow Email Notifications Approval History Odoo 17 Compatible

Overview

This module helps companies control vendor onboarding through a structured approval workflow. Users can assign a vendor approval group, submit a vendor for approval, and allow approvers to review step by step until the vendor is approved or rejected.

It is especially useful for procurement, finance, and administration teams that need stronger governance and clear approval traceability before a vendor can be used.

Key Features

Feature Description
Separate Vendor Approval Engine Uses dedicated models for vendor approval groups, levels, and approval history.
Approval Group Configuration Create multiple approval groups and define approval levels with sequence ordering.
Multiple Approvers per Level Assign one or more users at each level and show current pending approvers on the vendor form.
Sequence-Based Workflow Approval moves from one level to the next until final approval or rejection.
Email Notifications Automatically notifies approvers and stakeholders with direct vendor links.
Approval History & Audit Trail Tracks request, approval, rejection, approver, timestamp, and notes.

How the Workflow Works

  1. Create a Vendor Approval Group with one or more levels.
  2. Assign approvers to each level and define the sequence.
  3. Select the approval group on the vendor form.
  4. Click Submit for Approval.
  5. Approvers review and approve or reject level by level.

Configuration Steps

  1. Create a Vendor Approval Group.
  2. Add approval levels and set sequence.
  3. Assign approver users to each level.
  4. Open a vendor record.
  5. Select the Vendor Approval Group.
  6. Submit the vendor for approval.
  7. Approvers review, approve, or reject.

Multi-Company Support

The module can be configured so users only see approval groups that belong to the current company. This keeps company-specific workflows separated and avoids cross-company confusion.

  • Company-wise approval groups
  • Domain filtering on vendor form
  • Optional record rules for stricter security
