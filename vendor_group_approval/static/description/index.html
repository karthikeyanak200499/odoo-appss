Key Features

Designed for clarity on the Odoo Apps Store and easy understanding for business users and administrators.

🏢

Separate Vendor Approval Engine

Uses dedicated models for vendor approval groups, levels, and approval history instead of mixing logic with purchase approvals.

📋

Approval Group Configuration

Create multiple vendor approval groups and define approval levels with drag-and-drop sequence ordering.

👥

Multiple Approvers per Level

Assign one or more users to each approval level and show the current pending approvers clearly on the vendor form.

🔄

Sequence-Based Workflow

Once submitted, the approval moves from one level to the next based on configured sequence until final approval or rejection.

✉️

Email Notifications

Approval History & Audit Trail

Track request, approval, rejection, approver, timestamp, and notes for full visibility.

How the Workflow Works

Create Group

Configure a Vendor Approval Group with one or more approval levels.

Assign Approvers

Add users to each approval level and set the level sequence.

Select Group

Choose the approval group on the vendor form.

Submit

Click Submit for Approval to move the vendor to the first level.

Approve or Reject

Approvers act level by level until the vendor is approved or rejected.

Configuration Steps

  1. Create a Vendor Approval Group.
  2. Add approval levels and set the sequence.
  3. Assign approver users to each level.
  4. Open a vendor record.
  5. Select the Vendor Approval Group.
  6. Submit the vendor for approval.
  7. Approvers review, approve, or reject.

Multi-Company Support

The module can be configured so users only see approval groups that belong to the current company. This keeps company-specific workflows separated and prevents cross-company confusion.

  • Company-wise approval groups
  • Domain filtering on vendor form
  • Optional record rules for stricter security
