Vendor Group Approval

Structured vendor approval workflow for Odoo 17 with multi-level approvals and full audit history

Key Features

Approval Groups

Create vendor approval groups and configure multi-level approval workflows.

Multi-Level Approvals

Assign multiple approvers to each level with sequence-based workflow.

Email Notifications

Automatic email notifications with direct vendor record link.

Approval History

Full audit trail including approver name, time, and notes.

Multi Company Support

Approval groups can be configured company-wise.

Clean Vendor Integration

Approval workflow integrated directly into the vendor form.

Included Models

vendor.approval.group vendor.approval.level vendor.approval.matrix res.partner extension
Field Description
Vendor Approval Group Select the workflow group for vendor approval
Current Approval Level Displays the active approval stage
Pending At Shows the current approver users
Approval State Draft / Pending / Approved / Rejected

Workflow

  1. Create Vendor Approval Group
  2. Add approval levels
  3. Assign approver users
  4. Select group in vendor form
  5. Submit vendor for approval
  6. Approvers approve or reject
