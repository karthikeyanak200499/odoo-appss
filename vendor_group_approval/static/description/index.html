Vendor Group Approval

Structured vendor approval workflow for Odoo 17 with configurable approval groups, multi-level approvals, email notifications and approval history.

Main Features

Approval Groups

Create vendor approval groups for different workflows.

Multi-Level Approval

Configure multiple approval levels with sequences.

Multiple Approvers

Assign multiple users to approve vendors.

Email Notifications

Automatic email alerts for approval requests.

Approval History

Track all approvals and rejections.

Multi Company

Configure approval groups company-wise.

Workflow

1. Create Approval Group
Define vendor approval workflow. 		2. Configure Levels
Add multiple approval levels. 		3. Assign Approvers
Select users responsible for approval. 		4. Submit Vendor
Vendor moves to approval workflow. 		5. Approve / Reject
Approvers process vendor request.
